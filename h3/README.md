# MiniMax H3 test clip

`s04_nulla_bench_H3_GITS.mp4` is shot 4 re-rendered on MiniMax H3 instead of Wan 2.2, for comparison
against the same shot in the main film.

    model     minimax_h3_ref2va_pruned_int8_convrot
    lora      h3_gits_aesthetic_124f_r16_20260812_compiled20steady, step 452, strength 1.0
    encoder   qwen3vl_32b_minimax_h3_nvfp4_awq
    sampler   res_multistep, simple scheduler, 20 steps
    size      1024x576, 124 frames, 24 fps
    refs      @nulla (character), @kiosk (location), named reference registry project "reaper_queue"

Audio on this clip is generated by the model itself, not added afterwards.

The main film currently in the repo root used Wan 2.2 at 4 steps and 832x480, which is why it looks
softer and why character identity drifts. This clip is the quality target for a full re-render.

Note on references: approving a three panel character sheet as the identity reference did not work.
The first attempt returned an unrelated elderly man. Re-approving from a single cropped portrait of
the same sheet fixed it. Use single portraits for character aliases.
